# Coursatrix 文件规范 v1

所有导入先解析和校验，预览后确认。导入文件限制 **4 MiB**；最多 1000 门课程、5000 条安排、5000 条计划；每天 1–48 节、学期 1–60 周。课程名/教师最多 160 字符、地点 200、备注 2000。限制用于防止损坏或异常文件耗尽资源，不限制为某个学校的固定节数。

## 1. 专用文件

扩展名 `.coursatrix`，内容为 UTF-8 JSON（可读可审计，**不是加密文件**）：

```json
{
  "format": "coursatrix",
  "schemaVersion": 1,
  "kind": "TIMETABLE",
  "exportedAt": "2026-09-01T08:00:00Z",
  "data": {
    "semester": {"id": "example-term", "school": "示例大学", "name": "示例学期", "firstMonday": "2026-09-07", "weekCount": 20},
    "periods": [{"number": 1, "start": "08:00", "end": "08:45"}],
    "courses": [{"id": "example-course", "semesterId": "example-term", "name": "示例课程", "teacher": "", "color": "#6960CE", "note": ""}],
    "meetings": [{"id": "example-meeting", "courseId": "example-course", "weekday": 1, "startPeriod": 1, "endPeriod": 1, "weeks": [1, 3, 5], "location": "示例教室"}],
    "tasks": [],
    "preferences": {"theme": "SYSTEM", "showWeekend": true}
  }
}
```

- `format` 固定为 `coursatrix`；目前仅支持 `schemaVersion=1`，未知版本不静默猜测。
- `kind=BACKUP`：完整恢复会替换学期、作息、课程、安排、计划和外观。
- `kind=TIMETABLE`：只分享课表；`tasks` 必须为空、课程 `note` 必须为空；导入会替换学期/作息/课程，保留本地计划和外观。无法匹配的原课程关联解除。
- 分享时可清空 `teacher`/`location`，但学校/学期名称仍保留，导出前自行核对。
- `firstMonday` 必须为教学第一周的周一，ISO 日期；所有节次按 1 开始连续编号，`HH:mm` 本地时间递增且不能重叠。
- 课程与安排分离：教师属于课程；地点、星期、节次和周次属于每条安排。一门课可在不同周次和教室上多次。
- `weeks` 是不重复的显式整数集合，不用单双周布尔值推断；所有值必须在本学期范围内。
- 每门课程至少一条安排；标识不得重复，关联不得断裂；时段重叠可以存在，会提示但不删除。
- 任务字段：`id/title/kind/dueDate/completed/courseId/note`；`kind` 为 `TASK/HOMEWORK/EXAM`；日期与关联可以为 `null`。外观 `theme` 为 `SYSTEM/LIGHT/DARK`。
- 课程、安排与任务标识在完整备份中保留。日期无时区，导出时间为带偏移的 ISO 时间；课程按设备本地日期/时间计算。

## 2. CSV

推荐从应用导出或使用 `samples/courses-template.csv`。编码必须为 **UTF-8**，支持 BOM、LF/CRLF、双引号转义、含逗号/换行的被引号包围的字段。

| 列名 | 必填 | 规则 |
|---|---|---|
| 课程名称 | 是 | 去除首尾空白后不为空 |
| 教师 | 否 | 与课程名一起用于课程分组 |
| 教室 | 否 | 此条安排的地点 |
| 星期 | 是 | 1–7、周一至周日、星期一至星期日 |
| 开始节次 | 是 | 当前作息范围内的整数 |
| 结束节次 | 是 | 不早于开始节次，且在当前作息范围内 |
| 周次 | 是 | `1-16`、`1,3,5`、`1-16单`、`2-16双`，也接受 `(单)/(双)` 后缀 |
| 颜色 | 否 | `#RRGGBB`；缺省时分配内置颜色 |
| 备注 | 否 | 同一课程的私人备注，导出 CSV 时包含 |

一行是一条安排；同名、同教师的行组成一门课，因此它们的颜色和备注需要一致。若本地有刻意分开的同名同教师课程，CSV 不保证保留这种分组；请使用专用完整备份进行无损迁移。CSV 不携带学期名称、第一周日期或作息时间。

示例：

```csv
课程名称,教师,教室,星期,开始节次,结束节次,周次,颜色,备注
示例数学,示例教师,A101,1,1,2,1-16,#6960CE,
示例数学,示例教师,B202,4,3,4,"1,3,5",#6960CE,
```

### 合并与替换

- 文件内完全相同的安排去重并提示数量。
- 合并：按课程名+教师匹配本地课程；匹配时保留本地颜色/备注；新安排合并，已存在的完整相同安排跳过。
- 完整相同指：同一课程、星期、起止节次、排序去重后的周次和教室全部一致。
- 替换：只替换课程/安排，保留学期作息和计划，解除失效关联。
- 学期/作息在预览之后被修改时，CSV 需要重新导入。
- 非法行显示原文件行号（含多行引号字段的物理行号），**任何错误均阻止整个文件写入**，最多显示 100 条错误。
- 时间冲突不等于文件损坏：允许确认，但课表中会保留所有重叠安排。

### 电子表格公式防护

导出时，可能被电子表格当成公式的字符串（去除起始空白后以 `= + - @` 开头，或以制表符/换行开头）加一个前置单引号。原本以单引号开头的值也会再加一个，以避免应用自身往返时丢失原始引号。导入器仅在后续内容符合这一防护规则时去掉一层前置引号。这是本格式的约定，外部手工写入同类单引号的 CSV 也会按此规则解码。

不要仅依赖逗号/引号转义来阻止公式执行。无损、无歧义备份应使用 `.coursatrix`。

## 3. 学校 XLS 的转换边界

`tools/convert_school_xls.py` 只适配包含七天表头、连续节次、起止时间、单列纵向合并课程、`教师【周次】` 和省略号分隔多课程的旧版 XLS。它不是任意 XLS/XLSX 解析器，不运行宏、不联网、不读取浏览器或教务账号。

- 合并行决定连堂起止节次，格内多个课程拆为多条安排。
- 显式周次与单双周展开为整数集合。
- 转专用文件必须由使用者提供真实第一周周一，绝不根据课程开始周反推开学日期。
- 原始学生姓名/学号/班级不写入结果；学校、课程、教师、教室仍可能构成个人日程信息，请自行决定分享范围。
- 未识别结构和格式立即报错，不跳过未知课程并伪装转换成功。

## 学校 Excel 网格课表（仅导入）

- 格式：Excel 97-2003 `.xls`（OLE2 + BIFF8）或 Excel 2007+ `.xlsx`（Office Open XML）。只读取第一个工作表的单元格值和合并区域；公式只取已保存的结果，不执行宏；加密文件会被拒绝。`.xlsx` 解压后限制 32 MiB，拒绝含 DOCTYPE 的 XML。
- 结构：前 20 行内有「星期一」（或「周一」）起的表头行，至少 5 天；表头左侧列中有从 1 连续编号的节次（数字或「第1节」）；可选「时间」列，每格含两个 `H:mm`。
- 课程格：`课程名`、`教师【周次】`、`教室` 各占一行；同一格多门课用「………」分隔。周次如 `5-16周`、`5-8,10-10,12周`、`6-16(双)周`，单双周按每段生效。纵向合并单元格表示连堂，跨多天的合并会被拒绝。
- 结果按「分享课表」方式替换学期作息与课程（学期开始日期由用户在预览中确认），保留本地计划；同名同教师的课程沿用原 ID、颜色与备注。学校名称取表头上方「…大学/学院」单元格；学生姓名、学号、班级不会被读取。

## PDF（仅导入，需人工核对）

- 识别方式：用 pdfbox-android 提取第一页的文字坐标和表格线；没有文字的扫描版 PDF 会被拒绝。文件上限 20 MiB。
- 表格重建（`core/transfer/layout`）：以同一行中至少包含周一至周五的「星期X/周X」为列锚点，以表头下方、首列左侧依次出现的 1、2、3… 为行锚点。单元格范围取自 PDF 矢量表格线，没有表格线时按文字位置（会提示「节次按文字位置推测」）。行锚点区域若每行都有两个时间，可选择同时导入作息。
- 单元格文字：`课程名 / 教师【周次】/ 地点`（允许换行折断）或部分课表应用导出的 `课程名@地点`；多门课以 `………` 行分隔。无法确定的内容不猜测，而是在核对界面标红。
- 导入：核对后与 CSV 相同，使用当前学期与作息合并或替换课程；若选择使用识别出的作息，则改为替换课表。
